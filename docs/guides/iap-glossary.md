# 결제 용어집

- 결제 코드·문서·PR에 나오는 말을 한곳에 모은 것. 처음 보는 말이 나오면 여기부터
- 세팅과 출시 순서는 [`iap-store-setup.md`](iap-store-setup.md), 테이블과 칸의 이유는 [`spec/erd.md`](../spec/erd.md), 결정은 [ADR-0002](../adr/0002-iap-design.md)·[ADR-0003](../adr/0003-iap-compliance.md), 조사는 `reports/2026-11-19-iap-pitfalls.md`

## 1. 상품과 권한

| 말 | 뜻 | 우리에게서 |
|---|---|---|
| 인앱결제(IAP) | 앱 안에서 애플·구글 결제창으로 사는 것. 돈은 스토어가 받고 수수료를 뗀 뒤 정산해 준다 | 결제 전부 |
| 결제 경로(route) | 결제를 처리한 곳. `apple`, `google`. 나중에 `stripe`, `onestore` | 모든 결제 테이블의 `route` (D19) |
| 자동 갱신 구독 | 기간마다 저절로 다시 결제되는 상품 | 구독 plus(월·연) |
| 소모성(consumable) | 여러 번 살 수 있는 상품. 스토어는 "샀다"를 기억하지 않아 복원이 안 된다 | 추가 선반 (D1) |
| 비소모성(non-consumable) | 계정당 한 번만 사는 영구 상품. 스토어가 기억해 복원된다 | 쓰지 않음 |
| 권한(entitlement) | 결제로 얻는 것. "plus 구독 중", "2026년 책장 유료 칸 2개" | 저장하지 않고 계산 (D5) |
| 요금제(base plan) | 구글에서 구독 상품 하나에 붙는 월·연 같은 결제 방식. 애플은 상품 ID가 곧 요금제 | `plan_id`, `iap_plans` |
| 구독 그룹 | 애플에서 서로 바꿔 탈 수 있는 구독 묶음. 한 그룹에서는 하나만 구독된다 | 월·연을 한 그룹에 |

## 2. 거래를 가리키는 값

| 말 | 뜻 | 우리에게서 |
|---|---|---|
| 거래 ID(transactionId) | 애플의 결제 1건 번호. 갱신마다 새로 생긴다. 숫자라 추측할 수 있다 | `transaction_id` |
| 원 거래 ID(originalTransactionId) | 애플 구독의 첫 거래 번호. 갱신돼도 같아서 같은 구독 1건의 결제들을 묶는다 | `original_id` |
| 구매 토큰(purchaseToken) | 구글이 구매마다 주는 긴 문자열. 추측할 수 없다. 구독은 다시 시작·요금제 변경 때 새로 나온다 | 구글의 `transaction_id`·`original_id` |
| 주문 ID(orderId) | 구글 결제 1건 번호. 구독은 갱신마다 `..0`, `..1`처럼 늘어난다 | 구글 구독의 `transaction_id` |
| `linkedPurchaseToken` | 구글에서 새 구매 토큰이 이어받은 옛 토큰. 요금제를 바꾸거나 다시 구독하면 새 토큰이 나오는데, 이 값으로 옛 구독을 찾아 끝낸다 | D6 |
| 구독 1건 | 처음 구독한 때부터 해지·결제 실패로 끝날 때까지 자동 갱신으로 이어진 결제 묶음. 결제는 여러 번이어도 구독은 1건 | `iap_subscriptions` 1줄 (`erd.md` 3.4) |
| JWS (서명된 거래) | 애플이 서명한 거래 정보. 구매한 기기만 가진다. 서명을 확인하면 위조가 아님을 안다 | 앱이 내는 `proof` (#43) |
| 계정 연결 값 | 결제할 때 앱이 스토어에 넘기는 무작위 UUID. 스토어가 영수증·알림마다 돌려준다. 애플 `appAccountToken`, 구글 `obfuscatedAccountId` | `iap_account_tokens` (D7) |
| storefront / regionCode | 결제한 나라의 스토어. 애플은 세 글자(`KOR`), 구글은 두 글자(`KR`). 서버는 둘 다 두 글자 `KR`로 맞춰 저장 | `country` (D20) |

## 3. 결제 뒤에 할 일

| 말 | 뜻 | 우리에게서 |
|---|---|---|
| 서버 검증 | 앱이 "샀다"고 해도 믿지 않고 서버가 스토어에 직접 물어 확인하는 것 | `POST /iap/purchases` (D18) |
| 확인(acknowledge) | 구글에 "받았다"고 알리는 것. 3일 안에 안 하면 구글이 자동 환불한다 | `confirmed_at` |
| 소비(consume) | 구글 소모성 상품을 "다 썼다"고 알리는 것. 해야 같은 상품을 다시 살 수 있다. 소비도 확인으로 친다 | `consume` 칸 |
| 거래 끝내기(finish) | 앱이 스토어에 "처리했다"고 알리는 것. 안 끝내면 다음 실행에 같은 거래가 다시 온다 | 앱 `iapShouldFinish` |
| 복원(restore) | 기기를 바꾸거나 다시 깔았을 때 스토어에 산 것을 다시 묻는 것. 소모성은 돌아오지 않는다 | 구매 복원 단추, D8 |
| 멱등(idempotent) | 같은 요청을 여러 번 해도 결과가 한 번 한 것과 같음 | 유일 제약 (D6) |
| 원장(ledger) | 지우지 않고 쌓기만 하는 기록. 바뀐 것도 새 상태로 남긴다 | `iap_purchases` |

## 4. 구독의 상태

| 말 | 뜻 | 우리에게서 |
|---|---|---|
| 해지 예약 | 자동 갱신을 끈 상태. 이번 기간 끝까지는 쓸 수 있다 | `auto_renew=false` (D12) |
| 결제 실패 유예(grace period) | 갱신 결제가 실패해도 스토어가 며칠 더 쓰게 해 주는 기간. 그 사이 카드를 고치면 끊기지 않는다 | `grace_until` (D11) |
| 계정 보류(account hold) | 유예가 끝나도 결제가 안 된 상태. 권한은 끊기지만 스토어가 한동안 다시 시도한다 | `state='inactive'` |
| 만료 | 기간이 끝나고 갱신되지 않음 | `state='inactive'` |
| 환불·취소(revoke) | 스토어가 돈을 돌려주고 권한을 거둠. 애플은 사용자가 애플에 요청하고, 구글은 개발자도 할 수 있다 | `state='revoked'` (D13) |
| 무료 체험·할인 제안 | 첫 기간을 싸게 또는 무료로. 우리는 두지 않는다 | D14 |

## 5. 알림

| 말 | 뜻 | 우리에게서 |
|---|---|---|
| 서버 알림 | 갱신·해지·환불이 생기면 스토어가 우리 서버로 바로 보내는 알림. 앱이 꺼져 있어도 온다 | `iap_notifications` |
| ASSN V2 | 애플 App Store Server Notifications 2판. 서명된 JSON. `notificationUUID`로 중복을 가린다 | `…/iap/notifications/apple` |
| RTDN | 구글 실시간 개발자 알림. Pub/Sub로 온다. 알림에는 종류와 구매 토큰만 있어 서버가 다시 조회한다 | `…/iap/notifications/google` |
| Pub/Sub | 구글 클라우드의 메시지 배달 서비스. "최소 한 번" 배달이라 같은 메시지가 또 올 수 있다 | `messageId`로 중복 차단 |
| 대조(reconcile) | 알림을 놓쳤을 때를 대비해 서버가 정기적으로 스토어에 상태를 다시 묻는 것 | #44, #46 |
| 결제 고지 | 우리가 유저에게 보내는 결제 안내(완료, 실패, 만료, 환불). 법으로 알려야 하는 것이 있다 | `iap_notices`, `legal/notice-templates.md` |

## 6. 환경

| 말 | 뜻 | 우리에게서 |
|---|---|---|
| 샌드박스 | 돈이 나가지 않는 시험 결제 환경. TestFlight·심사·라이선스 테스터가 쓴다 | `env='sandbox'`, `IAP_ALLOW_SANDBOX` (D15) |
| 운영(production) | 실제 결제 | `env='production'` |
| 애플 샌드박스 갱신 주기 | 시험용이라 연 구독이 1시간마다 갱신되는 등 실제보다 훨씬 빠르다 | 결제 세팅 6장 |
| 라이선스 테스터 | 구글에서 돈 없이 시험 결제할 수 있게 등록한 계정 | 결제 세팅 3-7 |

## 7. 법과 해외

| 말 | 뜻 | 우리에게서 |
|---|---|---|
| 청약철회 | 산 지 7일 안에 물리는 소비자 권리(전자상거래법). 디지털 상품은 미리 알리면 제한할 수 있다 | 약관 초안, ADR-0003 |
| 다크패턴 규제 | 해지를 숨기거나, 미리 골라 두거나, 거절한 사람에게 또 묻는 것을 금지 | 결제 화면 전부 |
| 거래 기록 보관 | 계약·결제 기록 5년, 분쟁 기록 3년 | 탈퇴해도 `SET NULL`로 남김 |
| 판매자(merchant of record) | 법적으로 물건을 판 쪽. 인앱결제는 스토어가 판매자라 대부분 나라의 세금을 스토어가 처리한다는 자료가 있다 | ADR-0002 해외 절 |
| 스토어 밖 결제 | 웹 결제·외부 결제 링크. 나라마다 허용 범위가 다르다(미국, EU, 한국) | D19로 자리만 열어 둠 |
