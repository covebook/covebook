# 화면 공통 규칙 (2026-11-19)

사용자 요청: "비슷한 항목은 글씨 크기·굵기·두께·색·아이콘까지 같게. 전부 조사해서 정리하고, 공통 규칙을 적용한 뒤 다시 정리."
같은 종류 항목은 **같은 공용 부품**(`app/lib/ui/kit.dart`)과 **같은 역할 값**(`app/lib/ui/theme.dart`의 AppType·AppColors, kit의 Space·Shape)을 쓴다.
화면 파일에서 크기·색·여백 숫자를 직접 쓰지 않는다. 바꿀 일이 있으면 부품이나 토큰을 고친다.

## 1. 글자
- 글자 크기·줄 높이는 AppType 역할만 쓴다. `fontSize`·`TextStyle(...)`을 화면에서 만들지 않는다(그림 그리는 공유 장면·종이 카드처럼 옛 앱 화소 값을 옮긴 곳은 예외, 그 파일 맨 위에 적는다).
- 덧칠(`copyWith`)은 색(ink·inkSoft·inkFaint·accent·danger·onAccent)만 허용한다. 역할에 이미 있는 색을 다시 칠하지 않는다.
- 숫자 폭 고정은 `.tnum`(theme 확장)으로 한다. `fontFeatures`를 화면에서 쓰지 않는다.
- 고른 칸만 굵게: `.strong`(theme 확장, uiBold). 다른 굵기 덧칠은 쓰지 않는다.

## 5. 보조 글·형식
- 정보 사이는 옅은 세로줄 `metaSep`(' | '), 그리는 것은 늘 `MetaText`(화면 읽기는 쉼표).
- 날짜 `dateShort`('11월 15일', 올해가 아니면 연도), 긴 날짜 `dateLong`.
- 시각은 '오후 9:05', 범위는 '오후 9:05-9:30'(`timeRange`). 재는 중인 시간은 '00:45'(`clock`), 지난 시간은 `formatDuration`, 1분 미만은 초까지 `formatDurationShort`.
- 개수는 '갈피 N개', '책 N권' 어순.

## 7. 단추·창
- 화면 아래 주요 단추와 시트 안 단추는 l(52). 줄 안 작은 단추는 s(40, 누르는 자리 48).
- 글자만 단추는 TextLink(밑줄 없음, 누르는 자리 48). 꺼짐 투명도는 하나(`Opa.disabled` 0.4).
- 저장 단추 이름은 '○○ 저장'. 고치기·지우기는 '수정'·'삭제'로 부른다.
- 확인창은 `appAlert` 하나. 시트에 '닫기' 단추를 두지 않는다(밖 누르기·내려 닫기).
- 쓰던 글이 있는 화면은 나갈 때 묻는다(갈피 남기기·갈피 수정·감상 쓰기·감상 수정).

## 8. 상자·여백·색
- 흰 화면 안 회색 상자 없음(토스식). 안내 글은 sub, 오류 글은 sub danger. 상자가 꼭 필요하면 테두리 상자 `OutlineBox`.
- 여백은 Space, 모서리는 Shape, 색은 AppColors 토큰만. 머리카락 선은 `Hairline`.
- 누르는 자리는 최소 48(Space.hit).
