## 0. 요약

- 꼭 만들어야 하는 것: 화면 6개와 서버 기능 3개 (2장)
- 알림 채널 결론
  - 앱 안 알림함: 필수. 지금 우리가 유저에게 닿을 수 있는 유일한 확실한 수단
  - 기기 예약 알림(로컬 알림): 권장. 서버 푸시 없이 갱신 전 알림 가능
  - 서버 푸시, 이메일, 카카오 알림톡: 지금은 안 만듦. 필요해지는 조건을 적어 둠 (3장)
- 지금 앱에 없는 것: 푸시, 이메일 발송, 전화번호, 사업자 정보 화면, 구매 내역 화면, 구독 관리 화면
- 사업자 전화번호가 필요함. 지금은 문의가 메일뿐인데 법은 전화번호와 전자우편주소를 함께 표시하라고 함

## 3. 알림 채널 판단

### 3-1. 채널별 결론

| 채널 | 지금 | 필요한 것 | 결론 |
|---|---|---|---|
| 앱 안 알림함·화면 | 없음 | 화면 하나 | **필수** (F7) |
| 기기 예약 알림 (로컬 알림) | 없음 | 알림 권한, 패키지 하나. 서버 불필요 | **권장** (F12) |
| 서버 푸시 | 없음 | FCM·APNs 설정, 토큰 저장, 발송 서버 | 보류. 조건은 3-3 |
| 이메일 | 없음 | 처리방침 개정(고지 용도 추가), 발송 서비스. 주소는 로그인 계정에 있음 | 보류. 조건은 3-3 |
| 카카오 알림톡 | 없음 | 전화번호 수집, 사업자·채널·딜러사 계약, 템플릿 심사, 건당 비용 | 안 함 |

### 3-2. 법이 채널을 정해 두었나

- 가격 인상·유료 전환 동의: 통지 수단을 정한 조항이나 해석을 찾지 못함. "별도의 명시적 동의"가 요건이라 앱 안 동의 화면이 가장 확실함. 푸시만으로는 동의를 받을 수 없음
- 거래 고지(결제 완료, 갱신 예정): 수단 규정을 찾지 못함
- 광고성 정보: 채널마다 규칙이 있음 (3-4)
- 확인 필요: 한 법률 칼럼이 "자동 갱신 계약은 갱신일 14일 전까지 이메일·문자로 개별 통지(전자상거래법 제17조의2)"라고 적음. 다른 자료와 정부 보도자료에서는 이 조항을 확인하지 못함. 사실이면 연락처 수집이 필요해지므로 전문가 확인 1순위

### 3-3. 보류한 채널이 필요해지는 조건

| 조건 | 필요해지는 것 |
|---|---|
| 가격을 올려야 함 | 구독자 전원에게 닿을 수단. 앱을 안 여는 사람에게는 푸시나 이메일 |
| 무료 체험을 도입 | 유료 전환 전 동의. 애플은 대신 수집, 구글은 확인 못 함 |
| 갱신 전 개별 통지가 법 의무로 확인되거나 새로 생김 | 이메일 또는 문자 |
| 구독 권유·이벤트 알림을 보내고 싶음 | 광고 수신 동의 체계 전체 (3-4) |
| 해외 판매 (캘리포니아 등) | 가입한 방법과 같은 수단으로 갱신 안내 |

- 대비: 알림을 보내는 코드를 "채널" 인터페이스 뒤에 둠. 앱 안 알림함이 첫 구현이고 푸시·이메일은 구현만 추가
- 로그인 이메일은 2026-11-18부터 저장함. 다만 처리방침이 용도를 계정 표시로 한정함. 결제 고지에 쓸지는 정환과 결정 필요. 쓰려면 처리방침을 고쳐야 하고, 비로그인 구매자에게는 주소가 없음

### 3-4. 광고 알림을 보내려면 필요한 것 (지금은 안 보냄)

- 사전 수신 동의. "혜택 알림", "정보 제공" 같은 모호한 표현으로 동의받으면 안 됨 (KISA 안내서 2026-03 개정)
- 밤 9시~아침 8시 발송은 별도 동의
- 알림 앞에 `(광고)`와 보낸 곳, 끝에 수신거부 방법
- 푸시 광고에서 수신거부 화면으로 바로 이동. 로그인 같은 절차를 요구하면 안 됨 (2026-03 개정)
- 동의 뒤 2년마다 수신 동의 여부 재확인
- 결론: 거래 고지에 홍보 문구를 한 줄도 넣지 않음. 넣는 순간 위 전부가 필요해짐

### 3-5. 카카오 알림톡을 안 하는 이유

- 전화번호가 필요한데 우리는 수집하지 않음
- 사업자등록, 비즈니스 채널, 공식 딜러사 계약, 템플릿 심사(영업일 2일)가 필요하고 건당 비용이 듦
- 2026-11-01 심사 기준 변경으로 멤버십 만료·갱신을 유도하는 문구는 발송 불가. 결제 예정 금액·결제일·해지 방법 같은 사실 안내만 가능
- 유저가 적은 지금은 비용과 수집 부담이 이득보다 큼

## 6. 따로 확인할 것

- 만 14세 미만: 지금 가입 흐름에 나이 확인이 없음. 개인정보 수집에 법정대리인 동의가 필요한지, 결제까지 열어 둬도 되는지
- 사업자 전화번호를 개인 번호로 써도 되는지, 별도 번호가 필요한지
- "갱신일 14일 전 개별 통지" 조항의 실재 여부 (3-2)
- 거래 고지가 광고성 정보가 아니라는 구분 기준
