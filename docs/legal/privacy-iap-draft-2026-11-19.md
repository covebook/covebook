# 개인정보 처리방침 결제 부분 초안 — 2026-11-19

- 인앱결제를 켜기 전에 웹 전문(`server/internal/server/site/index.html`, 앱의 `privacyUrl`)에 넣을 문구 초안
- 결제를 켜기 전에는 웹에 올리지 않는다. 없는 수집을 적으면 오히려 틀린 고지가 된다
- 근거가 된 실제 동작: 서버 PR #21(표 V21), #43·#44(검증·알림), #46(구매 내역), #47(알림함). 머지 전이라 바뀌면 이 초안도 고친다
- 관련 결정: ADR-0003 L11(고지 기록), L14(약관·표시), L17(구매 내역), ADR-0002 D1(연도 책장마다 선반), D9(로그인 필수)
- 로그인이 필수가 되면(2026-11-19 결정) 처리방침 전문의 "로그인 없이 쓴다"는 문장도 함께 고쳐야 한다(`privacy-draft-2026-11-16.md`, 로그인 작업과 같이)

## 실제 동작 (코드로 확인)

- 서버에 저장하는 것
  - 스토어 거래 식별자: 애플 거래 ID·원 거래 ID, 구글 구매 토큰·주문 ID (`iap_purchases`, `iap_subscriptions`)
  - 상품 ID, 구독 요금제 ID, 구매·만료·환불 시각, 자동 갱신 여부, 결제 실패 유예 기한
  - 스토어가 알려 준 결제 금액·통화·나라 코드 (스토어가 주지 않으면 비어 있음)
  - 계정 연결 값: 구매할 때 스토어에 넘기는 무작위 UUID (`iap_account_tokens`). 이름·이메일과 무관. 추가 선반은 연도 책장마다 따로 발급해 어느 해 책장의 칸인지 찾는다 (ADR-0002 D1, 구현 예정)
  - 추가 선반이 열린 연도 책장
  - 스토어 서버 알림 원문 (`iap_notifications.payload`)
  - 앱 안 알림함에 보낸 결제 고지와 읽은 시각 (`iap_notices`)
  - 시험 결제(샌드박스)인지 여부
- 저장하지 않는 것
  - 카드 번호, 계좌 같은 결제 수단 정보 (앱 마켓이 처리)
  - 앱 마켓 계정의 이메일·이름
- 어디서 받나
  - 구매 직후 앱이 보내는 거래 정보
  - Apple App Store Server API·서버 알림, Google Play Developer API·실시간 개발자 알림
- 스토어로 보내는 것
  - 구매를 확인하려고 거래 ID·구매 토큰을 Apple·Google 서버에 조회한다
- 탈퇴하면
  - 로그인 연결, 독서 기록, 사진은 지운다 (지금과 같음)
  - 결제 기록(거래, 구독, 알림 원문, 결제 고지)은 지우지 않고 계정과의 연결만 끊는다 (`user_id`를 NULL로)
  - 계정 연결 값 표는 계정과 함께 지운다
- 기기에 저장하는 것
  - 이용 중인 상품 상태와 사업자 정보(빠른 표시용 캐시), 지난번 상태(알림 비교용). 로그아웃하면 지운다
- 아직 없는 것
  - 보관 기간이 지난 결제 기록을 지우는 작업. 출시 전에 서버에 만들어야 한다 (출시 점검표에 있음)

## 웹 전문에 넣을 문구

### 처리하는 개인정보 항목 (추가)

| 구분 | 항목 | 목적 |
|---|---|---|
| 유료 서비스 이용 시 | 앱 마켓 거래 식별자(거래 번호, 주문 번호, 구매 토큰), 구매한 상품, 추가 선반을 연 책장의 연도, 구매·만료·환불 일시, 구독 상태, 앱 마켓이 알려 준 결제 금액·통화·국가 | 구매 확인과 이용 권한 제공, 구독 갱신·해지·환불 반영, 구매 내역 제공, 결제 관련 안내, 분쟁 대응, 법령에 따른 기록 보존 |
| 유료 서비스 이용 시 | 결제 관련 안내를 보낸 기록(종류, 일시, 읽은 일시) | 결제 관련 안내를 했다는 기록, 문의·분쟁 대응 |

- 카드 번호 등 결제 수단 정보는 Apple, Google이 처리하며 책장 한켠은 받지 않습니다.

### 개인정보를 받는 곳 (추가)

- 유료 서비스의 거래 정보는 회원이 구매할 때 앱에서, 그리고 Apple(App Store)과 Google(Google Play)이 보내는 알림과 조회 결과로 받습니다.

### 보유 기간 (추가)

- 회원탈퇴를 하면 지체 없이 파기합니다. 다만 다음 정보는 「전자상거래 등에서의 소비자보호에 관한 법률」에 따라 계정과 분리해 정한 기간 동안 보관한 뒤 파기합니다.

| 보관하는 정보 | 기간 | 근거 |
|---|---|---|
| 계약 또는 청약철회 등에 관한 기록 | 5년 | 전자상거래법 시행령 제6조 |
| 대금결제 및 재화 등의 공급에 관한 기록 | 5년 | 전자상거래법 시행령 제6조 |
| 소비자의 불만 또는 분쟁처리에 관한 기록 | 3년 | 전자상거래법 시행령 제6조 |

### 회원의 권리 (추가)

- 회원은 앱의 '내 정보 › 구매 내역'에서 자기 결제 기록을 보고 복사할 수 있습니다.

## 확인 필요 (법률 전문가 또는 정환)

- 거래 식별자를 Apple·Google 서버에 조회하는 것이 개인정보 국외 이전(개인정보 보호법 제28조의8)에 해당하는지. 해당하면 이전받는 자, 나라, 항목, 목적, 기간을 적어야 함
- 결제 고지 기록과 스토어 알림 원문을 어느 기록(계약 기록 5년 / 불만·분쟁 기록 3년)으로 볼지. 이 초안은 5년으로 둠
- 앱 안 알림함 고지가 "광고성 정보"가 아니라는 판단(ADR-0003 L7)이 처리방침 문구에도 필요한지

## 앱 마켓의 개인정보 표시 (콘솔에서 바꿀 것)

- App Store Connect › 앱 개인정보: "구매 항목(Purchases) › 구매 내역" 추가. 사용자와 연결됨, 목적은 앱 기능
- Play Console › 데이터 보안: "금융 정보 › 구매 기록" 추가. 수집함, 공유 안 함, 목적은 앱 기능·계정 관리
- 출시 점검표(`docs/guides/iap-launch-checklist.md`)에서 체크한다
