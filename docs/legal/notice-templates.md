# 결제 고지 문구 템플릿

- 작성일: 2026-11-18
- 상태: 초안. 가격·날짜는 `{ }` 자리에 채움
- 근거: [ADR-0003 결제 법규 대응](../adr/0003-iap-compliance.md)
- 주의: 법률 검토 전 초안

## 쓰는 규칙

- `{ }`는 값이 들어갈 자리. 가격은 스토어가 주는 현지 가격 문자열을 그대로 넣음
- 거래 고지에는 혜택 홍보나 다른 상품 추천을 넣지 않음. 넣으면 광고성 정보가 됨
- 문구를 고치면 버전을 올림. 동의 기록과 발송 기록에 버전이 남음
- 다른 언어판은 같은 번호로 추가

| 자리 | 뜻 | 예 |
|---|---|---|
| `{상품}` | 요금제 이름 | 책장 한켠 플러스 (월) |
| `{가격}` | 스토어 현지 가격 | 스토어가 주는 문자열 |
| `{주기}` | 결제 주기 | 매월 / 매년 |
| `{다음 결제일}` | 다음 갱신일 | 2027년 1월 18일 |
| `{만료일}` | 권한이 끝나는 날 | 2027년 1월 18일 |
| `{스토어}` | 결제한 곳 | App Store / Google Play |

## T1. 결제 화면 표시 (v1)

결제 버튼 바로 위에 표시. 작은 글씨로 숨기지 않음.

```
{상품} · {가격} / {주기}

· {주기} 자동으로 결제됩니다.
· 다음 결제일 24시간 전까지 해지하지 않으면 같은 금액으로 갱신됩니다.
· 해지는 {스토어} 계정의 구독 관리에서 할 수 있습니다. 앱의 설정 > 구독 관리에서도 바로 갈 수 있습니다.
· 해지해도 이미 결제한 기간이 끝날 때까지 이용할 수 있습니다.
· 환불은 {스토어}의 환불 절차를 따릅니다.

이용약관 · 환불 안내 · 개인정보 처리방침
```

- "24시간 전"은 스토어 규칙. 스토어별로 다르면 그에 맞춤

## T2. 선반 구매 화면 표시 (v1)

```
추가 선반 {칸 수}칸 · {가격}

· 한 번 결제하면 계속 쓸 수 있습니다.
· 구매한 선반은 계정에 기록됩니다. 로그인해 두면 기기를 바꿔도 유지됩니다.
· 로그인하지 않고 구매하면 이 기기에서만 쓸 수 있고, 앱을 지우면 되찾지 못할 수 있습니다.
· 환불은 {스토어}의 환불 절차를 따릅니다.
```

## T3. 결제 완료 (v1)

```
{상품} 결제가 완료됐습니다.

· 결제 금액: {가격}
· 결제일: {결제일}
· 다음 결제일: {다음 결제일}
· 해지: 설정 > 구독 관리
```

## T4. 갱신 예정 (v1)

연 구독. 갱신일 전에 발송. 며칠 전인지는 나라별 규칙 표의 값.

```
{상품}이 {다음 결제일}에 갱신됩니다.

· 결제 예정 금액: {가격}
· 계속 이용하려면 할 일이 없습니다.
· 갱신을 원하지 않으면 {다음 결제일} 하루 전까지 설정 > 구독 관리에서 해지할 수 있습니다.
```

## T5. 가격 변경 동의 요청 (v1)

인상 전 30일 이내. 앱 안 화면에서 동의·거절을 명시적으로 받음. 거절 버튼을 동의 버튼과 같은 크기로.

```
{상품}의 가격이 바뀝니다.

· 지금 가격: {지금 가격} / {주기}
· 바뀌는 가격: {새 가격} / {주기}
· 적용일: {적용일} 이후 첫 결제부터

동의하지 않으면 {만료일}에 구독이 끝나고 더 이상 결제되지 않습니다.
동의한 뒤에도 설정 > 구독 관리에서 언제든 해지할 수 있습니다.

[ 동의하지 않음 ]   [ 바뀐 가격에 동의 ]
```

- 금지: "거부하지 않으면 동의로 봅니다" 같은 문구, 가입 때 약관으로 받은 일괄 동의
- 금지: 거절한 사람에게 다음 날 다시 띄우기

## T6. 유료 전환 동의 요청 (v1)

무료 체험·할인을 도입한 경우에만 사용. 지금은 쓰지 않음.

```
무료 체험이 {전환일}에 끝납니다.

· {전환일}부터 {가격} / {주기}이 결제됩니다.

동의하지 않으면 {전환일}에 체험이 끝나고 결제되지 않습니다.

[ 동의하지 않음 ]   [ 유료 전환에 동의 ]
```

## T7. 결제 실패 (v1)

```
{상품} 결제가 이뤄지지 않았습니다.

· {유예 종료일}까지는 계속 이용할 수 있습니다.
· {스토어} 계정의 결제 수단을 확인해 주세요.
· 그때까지 결제되지 않으면 구독이 끝납니다.
```

## T8. 구독 만료 (v1)

```
{상품} 구독이 끝났습니다.

· 만든 책장과 기록은 그대로 있습니다.
· 유료 벽지·선반 색은 기본 모양으로 보입니다. 고른 설정은 저장돼 있습니다.
```

- "다시 구독하면 원래대로 돌아옵니다" 같은 권유 문장은 넣지 않음. 넣으면 광고성 정보로 볼 여지가 있음

## T9. 환불 처리 (v1)

```
{상품} 결제가 환불 처리됐습니다.

· 환불일: {환불일}
· {구독인 경우: 구독이 종료됐습니다.}
· {선반인 경우: 해당 선반이 잠겼습니다. 꽂힌 책은 그대로 있습니다.}
· 환불 금액과 시기는 {스토어}에서 확인할 수 있습니다.
```

## T10. 해지 접수 (v1)

```
{상품}의 자동 갱신이 꺼졌습니다.

· {만료일}까지 이용할 수 있습니다.
· 이후에는 결제되지 않습니다.
```

## T11. 구독 관리 화면 (v1)

설정 첫 화면에서 한 번에 닿는 화면.

```
구독 관리

· 요금제: {상품}
· 상태: {이용 중 / 해지 예약 / 결제 확인 필요}
· 다음 결제일: {다음 결제일} · {가격}

[ {스토어}에서 해지하기 ]
[ 구매 복원 ]

환불 안내 · 이용약관
```

- 해지 버튼을 누르면 스토어 구독 관리 화면으로 바로 이동. 설문, 혜택 재안내, 재확인 팝업 없음

## T12. 탈퇴 화면의 구독 안내 (v1)

구독 중인 계정이 탈퇴하려 할 때.

```
지금 {상품}을 구독하고 있습니다.

· 탈퇴해도 {스토어} 구독은 자동으로 해지되지 않습니다.
· 먼저 {스토어}에서 구독을 해지해 주세요.

[ {스토어}에서 해지하기 ]   [ 탈퇴 계속 ]
```

## T13. 약관에 넣을 조항 (목록)

- 유료 서비스의 종류와 내용
- 결제 주기와 자동 갱신
- 가격 변경 시 사전 동의 절차
- 해지 방법과 해지 뒤 이용 기간
- 청약철회와 환불 기준, 스토어 환불 절차 안내
- 결제·해지·환불 문의 창구와 처리 기한
- 미성년자의 결제
- 결제 기록 보관 기간

## T14. 앱 심사 메모 (v1)

```
- 구독(월·연)은 자동 갱신 구독이며, 구매 복원은 설정 > 구독 관리에 있습니다.
- 추가 선반은 소모성 상품으로 등록했지만 한 번 구매하면 계정에 영구히 기록됩니다.
  로그인하면 어느 기기에서든 복원됩니다.
- 로그인 없이도 구매할 수 있습니다.
- 시험 계정: {아이디} / {비밀번호}
```
