# 결제 고지 문구 템플릿

- 작성일: 2026-11-18
- 상태: 초안. 가격·날짜는 `{ }` 자리에 채움
- 근거: [ADR-0003 결제 법규 대응](../adr/0003-iap-compliance.md)
- 주의: 법률 검토 전 초안

## 쓰는 규칙

- `{ }`는 값이 들어갈 자리. 가격은 스토어가 주는 현지 가격 문자열을 그대로 넣음
- 거래 고지에는 혜택 홍보나 다른 상품 추천을 넣지 않음. 넣으면 광고성 정보가 됨
- 문구를 고치면 버전을 올림. 동의 기록과 발송 기록에 버전이 남음
- 다른 언어판은 같은 번호로 추가

| 자리 | 뜻 | 예 |
|---|---|---|
| `{상품}` | 요금제 이름 | 책장 한켠 플러스 (월) |
| `{가격}` | 스토어 현지 가격 | 스토어가 주는 문자열 |
| `{주기}` | 결제 주기 | 매월 / 매년 |
| `{다음 결제일}` | 다음 갱신일 | 2027년 1월 18일 |
| `{만료일}` | 권한이 끝나는 날 | 2027년 1월 18일 |
| `{스토어}` | 결제한 곳 | App Store / Google Play |

## T1. 결제 화면 표시 (v2, 2026-11-26)

결제 버튼 바로 위에 표시. 작은 글씨로 숨기지 않음.

```
{상품} · {가격} / {주기}

· {주기} 자동으로 결제됩니다.
· 다음 결제일 24시간 전까지 해지하지 않으면 같은 금액으로 갱신됩니다.
· 해지는 {스토어} 계정의 구독 관리에서 할 수 있습니다. 앱의 설정 > 구독 관리에서도 바로 갈 수 있습니다.
· 해지해도 이미 결제한 기간이 끝날 때까지 이용할 수 있습니다.
· 결제하면 바로 이용이 시작됩니다. 이용을 시작한 유료 서비스는 청약철회가 제한될 수 있으며, 환불은 {스토어}의 환불 절차를 따릅니다.

이용약관 · 환불 안내 · 개인정보 처리방침
```

- "24시간 전"은 스토어 규칙. 스토어별로 다르면 그에 맞춤
- v1과 달라진 것: 청약철회 제한 표시를 넣음(ADR-0003 L19). 약관 (청약철회와 환불) 1항과 같은 말("제한될 수 있으며")을 씀
  - 디지털콘텐츠는 "철회 불가 표시"와 "시험 사용 상품 제공"이 둘 다 있어야 제한할 수 있다(전자상거래법 제17조 제6항 단서). 구독 혜택(유료 벽지·선반 색)을 만들 때 결제 전에 미리 적용해 보는 미리보기를 함께 만든다(시행령 제21조의2 제1호)

## T2. 선반 구매 화면 표시 (v3, 2026-11-26)

```
{연도}년 책장 · 추가 선반 {칸 수}칸 · {가격}

· {연도}년 책장에 선반 {칸 수}칸을 엽니다. 다른 해의 책장에는 열리지 않습니다.
· 한 번 결제하면 이 책장에서 계속 쓸 수 있습니다.
· 구매한 선반은 로그인한 계정에 기록되어 기기를 바꿔도 유지됩니다.
· 결제하면 바로 선반이 열려 청약철회가 제한됩니다. 환불은 {스토어}의 환불 절차를 따릅니다.
```

- v2와 달라진 것: 청약철회 제한 표시(ADR-0003 L19). 시험 사용은 잠긴 선반 미리보기(흐린 예시 책, `locked_rows.dart`)

- 상품은 1칸과 3칸 묶음 둘. 3칸 묶음은 그 해 책장에 산 칸이 없을 때만 보임 (ADR-0002 D1)
- 둘 다 보일 때 어느 쪽도 미리 고르지 않음. 묶음을 "추천"처럼 강조하지 않음 (다크패턴 규제)
- 묶음의 할인 표시는 스토어가 주는 두 가격만 나란히 보임. "○% 할인" 같은 계산 문구는 넣지 않음(나라·환율마다 달라짐)
- v1과 달라진 것: 연도 책장 표시, 로그인 없이 구매하는 경우의 문장 삭제(로그인 필수, ADR-0002 D9)

## T3. 결제 완료 (v2, 2026-11-26)

```
{상품} 결제가 완료됐습니다.

· 결제 금액: {가격}
· 결제일: {결제일}
· 다음 결제일: {다음 결제일}
· 해지: 내 정보 > 구독 관리
· 판매자 정보와 청약철회·환불 기준은 내 정보의 사업자 정보와 이용약관에 있습니다.
```

- 선반은 다음 결제일·해지 줄 대신 "{연도}년 책장의 선반 {칸 수}칸을 더 열 수 있습니다."
- 앱 안 알림함과 결제 직후 창, 구매 내역에 남는다. 계약 내용 서면(전자상거래법 제13조 제2항, 전자문서 포함)을 겸한다(ADR-0003 L20)
- v1과 달라진 것: 판매자 정보·철회 기준이 있는 곳을 알리는 줄. 청약철회 7일은 이 서면을 받은 날부터 센다(제17조 제1항 제1호)

## T4. 갱신 예정 (v1)

연 구독. 갱신일 전에 발송. 며칠 전인지는 나라별 규칙 테이블의 값.

```
{상품}이 {다음 결제일}에 갱신됩니다.

· 결제 예정 금액: {가격}
· 계속 이용하려면 할 일이 없습니다.
· 갱신을 원하지 않으면 {다음 결제일} 하루 전까지 설정 > 구독 관리에서 해지할 수 있습니다.
```

## T5. 가격 변경 동의 요청 (v1)

인상 전 30일 이내. 앱 안 화면에서 동의·거절을 명시적으로 받음. 거절 버튼을 동의 버튼과 같은 크기로.

```
{상품}의 가격이 바뀝니다.

· 지금 가격: {지금 가격} / {주기}
· 바뀌는 가격: {새 가격} / {주기}
· 적용일: {적용일} 이후 첫 결제부터

동의하지 않으면 {만료일}에 구독이 끝나고 더 이상 결제되지 않습니다.
동의한 뒤에도 설정 > 구독 관리에서 언제든 해지할 수 있습니다.

[ 동의하지 않음 ]   [ 바뀐 가격에 동의 ]
```

- 금지: "거부하지 않으면 동의로 봅니다" 같은 문구, 가입 때 약관으로 받은 일괄 동의
- 금지: 거절한 사람에게 다음 날 다시 띄우기

## T6. 유료 전환 동의 요청 (v1)

무료 체험·할인을 도입한 경우에만 사용. 지금은 쓰지 않음.

```
무료 체험이 {전환일}에 끝납니다.

· {전환일}부터 {가격} / {주기}이 결제됩니다.

동의하지 않으면 {전환일}에 체험이 끝나고 결제되지 않습니다.

[ 동의하지 않음 ]   [ 유료 전환에 동의 ]
```

## T8. 구독 만료 (v1)

```
{상품} 구독이 끝났습니다.

· 만든 책장과 기록은 그대로 있습니다.
· 유료 벽지·선반 색은 기본 모양으로 보입니다. 고른 설정은 저장돼 있습니다.
```

- "다시 구독하면 원래대로 돌아옵니다" 같은 권유 문장은 넣지 않음. 넣으면 광고성 정보로 볼 여지가 있음

```
· 환불일: {환불일}
· {구독인 경우: 구독이 종료됐습니다.}
· {선반인 경우: 해당 선반이 잠겼습니다. 꽂혀 있던 책은 내 책에 보관했습니다.}
· {선반을 열지 않은 결제인 경우(연도 모름): 어느 해 책장의 선반인지 확인하지 못해 선반을 열지 않고 환불했습니다.}
· 환불 금액과 시기는 {스토어}에서 확인할 수 있습니다.
```

## T11. 구독 관리 화면 (v1)

설정 첫 화면에서 한 번에 닿는 화면.

```
구독 관리

· 요금제: {상품}
· 상태: {이용 중 / 해지 예약 / 결제 확인 필요}
· 다음 결제일: {다음 결제일} · {가격}

[ {스토어}에서 해지하기 ]
[ 구매 복원 ]

환불 안내 · 이용약관
```

- 해지 버튼을 누르면 스토어 구독 관리 화면으로 바로 이동. 설문, 혜택 재안내, 재확인 팝업 없음

## T13. 약관에 넣을 조항 (목록)

- 유료 서비스의 종류와 내용
- 결제 주기와 자동 갱신
- 가격 변경 시 사전 동의 절차
- 해지 방법과 해지 뒤 이용 기간
- 청약철회와 환불 기준, 스토어 환불 절차 안내
- 결제·해지·환불 문의 창구와 처리 기한
- 미성년자의 결제
- 결제 기록 보관 기간
- 외부 제공 정보와 유료 서비스의 관계 (아래 T13-1)

### T13-1. 외부 제공 정보 조항 초안 (v1)

도서 표지와 서지 정보는 YES24 등 외부 제공처에서 받아 옴. 제공이 끊겨도 유료 서비스의 하자가 아님을 약관에 적어 둠. 지금 약관 제6조(외부 제공 정보), 제9조(책임의 제한)에 이어 붙임.

```
1. 유료 서비스의 내용은 추가 선반과 꾸미기 기능입니다. 도서 표지, 서지 정보 같은 외부 제공 정보는 유료 서비스의 대상이 아닙니다.
2. 외부 제공처의 정책 변경이나 제공 중단으로 표지가 바뀌거나 표시되지 않을 수 있습니다. 이 경우 제목이 적힌 기본 표지로 대체되며, 회원의 독서 기록과 책장 배치는 그대로 보관됩니다.
3. 제2항의 사유는 유료 서비스의 하자나 환불 사유가 되지 않습니다. 다만 서비스의 고의나 과실로 생긴 경우는 그렇지 않습니다.
```

- 결제 화면(T1, T2)에서 표지를 유료 혜택처럼 보이게 쓰지 않음. 쓰면 제1항과 어긋남
- 고의·중과실 책임까지 빼는 문구는 약관규제법상 무효. 제3항의 단서를 지우지 않음
- 확인 필요: 유료 구독자에게 이 면책이 통하는지는 전문가 확인 항목 (이슈 #18)

## T14. 앱 심사 메모 (v2, 2026-11-19)

```
- 책장 한켠은 독서 기록과 연도별 책장을 계정에 보관하고 기기 사이에 동기화하는 앱이라, 시작할 때 로그인이 필요합니다.
- 구독(월·연)은 자동 갱신 구독이며, 구매 복원은 내 정보 > 구독 관리에 있습니다.
- 추가 선반은 연도별 책장에 칸을 여는 소모성 상품입니다. 해마다 새 책장이 생기고 같은 상품을 여러 번 살 수 있어 소모성으로 등록했습니다.
  구매는 로그인한 계정에 영구히 기록되어 어느 기기에서든 그대로 보입니다.
- 시험 계정: {아이디} / {비밀번호}
```

## T15. 넘은 선반 결제 (v1, 2026-11-19)

- 언제: 두 기기에서 함께 사서 그 해 책장의 유료 선반이 3칸을 넘었을 때. 넘은 결제는 칸을 열지 않고 돌려준다(ADR-0002 D1)
- 어디: 앱 안 알림함, 앱을 열 때 창으로 한 번(중요 고지)

```
추가 선반이 열리지 않았습니다

{연도}년 책장은 다른 기기에서 먼저 결제해 유료 선반 3칸이 모두 열려 있었습니다. 이번 결제(선반 {칸 수}칸)는
- Google Play, 자동 환불 요청 성공: 자동으로 환불했습니다. 환불 금액과 시기는 Google Play에서 확인할 수 있습니다.
- Google Play, 요청 실패(서버가 다시 시도): 환불해 드립니다. 처리되면 Google Play에서 확인할 수 있습니다.
- App Store: Apple에 환불을 요청해 돌려받을 수 있습니다. Apple의 문제 신고 페이지에서 이 구매를 골라 환불을 요청해 주세요.

[Apple에 환불 요청하기]  (App Store만, reportaproblem.apple.com)
[나중에]  (아래 글자 단추. DESIGN 9장: 닫기 대신 나중에)
```

- 애플은 개발자가 대신 환불하는 API가 없다. 앱 안 환불 요청 창(StoreKit `beginRefundRequest`)은 지금 쓰는 Flutter 플러그인에 없어 웹 페이지로 보낸다
- 넘치는 일을 줄이려고 선반 결제창을 띄우는 동안 5분 예약을 건다. 다른 기기는 그동안 아래 문구를 본다(선반 구매 시트 안 오류 줄)

```
다른 기기에서 이 책장의 선반을 결제하고 있어요. 잠시 뒤 다시 시도해 주세요.
```
