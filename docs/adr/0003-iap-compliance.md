# ADR-0003: 결제 법규 대응 (고지, 동의, 해지, 기록)

- 상태: 제안 (정환 확인 후 "승인"으로 변경)
- 날짜: 2026-11-18
- 결정자: 범수, 정환
- 앞선 결정: [ADR-0001](0001-iap-server-go.md), [ADR-0002](0002-iap-design.md)
- 주의: 법률 자문이 아님. 공개 자료를 조사해 정리한 것. 출시 전에 전문가 확인 필요 (7장)

## 1. 배경

- 한국은 구독 결제 규제가 2025~2026년에 연달아 강화됨
  - 2025-02-14: 전자상거래법의 온라인 다크패턴 규제 시행 (6개 유형)
  - 2025-10-15: 구독 플랫폼에 첫 과태료 부과
  - 2026-03: KISA 정보통신망법 안내서 개정 (모호한 표현의 광고 동의 금지, 푸시 광고 수신거부 간소화)
  - 2026-05-27: 방미통위가 온라인 구독형 서비스 사업자용 안내서 첫 발간 (전기통신사업법 금지행위)
  - 2026-10-06: 공정위가 13개 유형 가이드라인 배포
  - 2026-11-06~26: 소비자보호 지침 개정안 행정예고 (탈퇴·해지 방해 기준 구체화)
- 결제를 스토어가 처리해도 앱 화면, 고지, 해지 경로, 약관은 우리 책임 범위
- 해외 판매 계획이 있어 나라마다 다른 고지 규칙을 담을 구조가 필요

## 2. 누가 무엇을 책임지나

| 일 | 스토어 | 우리 |
|---|---|---|
| 결제 직전 금액·주기·갱신 조건 표시 | 결제 시트에 표시 (앱마켓 사업자 의무) | 결제 화면에 같은 내용을 먼저 표시 |
| 무료 체험·할인의 유료 전환 동의 (한국) | 애플이 이메일·푸시·앱 내 시트로 동의 수집 | 체험·할인을 도입할 때만 해당 |
| 가격 인상 동의 | 애플은 한국을 "동의 필요" 국가로 분류 | 인상 계획·고지, 동의 기록 보관 |
| 환불 결정과 지급 | 스토어 | 환불 알림을 받아 권한 회수, 문의 대응 |
| 구독 해지 처리 | 스토어 계정 설정에서 | 앱 안에서 해지 경로를 쉽게 안내 |
| 약관, 환불·해지 정책, 사업자 정보 표시 | - | 우리 |
| 거래 기록 보존 | - | 우리 |
| 광고성 알림의 수신 동의 | - | 우리 |

- 구글의 한국 동의 절차는 확인하지 못함. 구글 정책은 "구독·해지·환불 정책 변경을 알리는 것은 개발자 책임"이라고 명시
- 전자상거래법의 동의 의무는 "통신판매업자"에게 있음. 스토어 결제에서 개발사가 그 지위인지는 자료가 엇갈림. 개발사를 통신판매업자로 보고 준비

## 3. 결정 요약

| 번호 | 정할 것 | 결정 |
|---|---|---|
| L1 | 결제 화면 표시 | 가격, 주기, 자동 갱신, 해지 방법, 환불 정책을 결제 버튼 앞에 표시 |
| L2 | 화면 금지 사항 | 미리 선택된 옵션, 숨긴 가격, 거절을 어렵게 한 버튼, 반복 팝업을 쓰지 않음 |
| L3 | 해지 경로 | 설정 첫 화면에서 한 번에 닿는 "구독 관리". 설문·재확인·본인인증을 끼우지 않음 |
| L4 | 탈퇴 경로 | 설정 첫 화면에서 한 번에 닿게. 구독 중이면 스토어에서 해지해야 함을 안내 |
| L5 | 가격 인상 | 원칙적으로 하지 않음. 해야 하면 스토어 동의 절차 + 우리 기록 |
| L6 | 무료 체험·할인 | 출시 때 없음. 도입하면 유료 전환 동의 대상이 됨 |
| L7 | 고지 종류 | 거래 고지 8종을 정의. 광고와 섞지 않음 |
| L8 | 고지 채널 | 앱 안 알림함이 기준. 푸시와 이메일은 보조 |
| L9 | 갱신 전 알림 | 연 구독은 갱신 전에 알림. 며칠 전인지는 나라별 규칙 표로 |
| L10 | 동의 기록 | 누가, 무엇에, 어떤 문구에, 언제 동의했는지 저장 |
| L11 | 고지 발송 기록 | 보낸 고지를 저장 |
| L12 | 나라별 규칙 | 고지 종류·시점·필수 여부를 표로 관리 |
| L13 | 기록 보존 | 결제·계약 기록 5년. 탈퇴해도 분리해 보관 |
| L14 | 약관·표시 | 결제·해지·환불 정책과 문의 방법을 약관에, 사업자 정보를 앱에 표시 |
| L15 | 광고성 알림 | 거래 고지와 분리. 수신 동의, 야간 동의, 2년마다 재확인 |
| L16 | 미성년자 결제 | 환불은 스토어 절차로 안내. 환불 알림이 오면 권한 회수 |
| L17 | 구매 내역 화면 | 유저가 자기 결제 기록을 앱에서 보고 저장할 수 있게 |
| L18 | 알림 채널 구조 | 채널을 인터페이스 뒤에 둠. 첫 구현은 앱 안 알림함과 기기 예약 알림 |

## 4. 결정과 근거

### L1. 결제 화면에 표시할 것

- 표시 항목
  - 가격 (스토어가 주는 현지 가격, ADR-0002 D22)
  - 결제 주기 (월 / 연)
  - 자동 갱신된다는 사실
  - 해지 방법 (어디서 하는지)
  - 환불 정책 링크, 약관 링크, 개인정보 처리방침 링크
- 근거
  - 숨은 갱신(전자상거래법 제13조 제6항), 순차공개 가격책정(제21조의2 제1항 제1호)이 금지 유형
  - 구글 정책: 구독 조건과 비용을 명확히 표시, 해지 방법을 앱에서 안내
  - 일본 특정상거래법: 최종 확인 화면에 금액·결제 시기·해지 조건 표시. 해외 판매 때도 같은 화면으로 대응 가능
- 문구는 [고지 문구 템플릿](../legal/notice-templates.md)에 둠

### L2. 화면에서 하지 않을 것

- 법이 금지한 6개 유형 (2025-02-14 시행)

| 유형 | 조항 | 우리 화면에서 뜻하는 것 |
|---|---|---|
| 숨은 갱신 | 제13조 제6항 | 증액·유료 전환을 동의 없이 하지 않음 |
| 순차공개 가격책정 | 제21조의2 제1항 제1호 | 첫 화면 가격과 최종 가격이 같아야 함 |
| 특정옵션의 사전선택 | 제2호 | 연 요금제나 추가 상품을 미리 선택해 두지 않음 |
| 잘못된 계층구조 | 제3호 | "구독" 버튼만 크게, "닫기"는 안 보이게 하지 않음 |
| 취소·탈퇴 등의 방해 | 제4호 | 해지를 가입보다 복잡하게 만들지 않음 |
| 반복간섭 | 제5호 | 거절한 사람에게 같은 팝업을 다시 띄우지 않음 |

- 제재: 시정조치, 과태료(1차 100만 원, 2차 200만 원, 3차 이상 500만 원), 영업정지(1차 3개월, 2차 6개월, 3차 12개월) 또는 과징금
- 전기통신사업법 금지행위도 겹침: 동의 없는 유료 가입 유도, 요금·결제조건 은폐·누락, 정당한 사유 없는 해지 제한 (방미통위 안내서 2026-05-27). 앱으로 쓰는 서비스의 해지를 PC·웹으로만 받는 것이 위반 사례
- 가이드라인(2026-10-06)은 13개 유형으로 넓혀 해석 기준을 제시. 법적 구속력은 없지만 집행 기준으로 쓰임
- 결제 화면 닫기 버튼은 항상 보이게, 구독 권유 팝업은 거절하면 같은 세션에서 다시 띄우지 않음

### L3. 해지 경로

- 결정
  - 설정 첫 화면에 "구독 관리" 항목
  - 누르면 현재 요금제, 다음 결제일, "스토어에서 해지하기" 버튼
  - 버튼은 스토어의 구독 관리 화면으로 바로 이동
  - 해지 전에 설문, 혜택 재안내, 본인인증을 끼우지 않음
- 근거
  - 제21조의2 제1항 제4호: 해지를 가입보다 복잡하게 하면 위반
  - 가이드라인 권고: 로그인 첫 화면이나 거기서 한 번에 닿는 화면에 배치
  - 2026-11 지침 개정안의 위반 예시: 탈퇴 버튼을 찾기 어려운 곳에 둠, 가입 때 없던 본인인증 요구, 설문에 답해야 진행
  - 2025-10 첫 과태료 사례: 중도해지 관련 사실을 제대로 안내하지 않음
  - 구글 정책: 앱 안에서 쉽게 쓸 수 있는 온라인 해지 수단 제공
- 해지 뒤 동작: 만료일까지 권한 유지 (ADR-0002 D12). 화면에 "○월 ○일까지 이용 가능" 표시

### L4. 탈퇴 경로

- 결정: 설정 첫 화면에서 한 번에 닿게. 구독 중인 계정이 탈퇴하면 "스토어 구독은 자동으로 해지되지 않음"을 알리고 해지 화면으로 안내
- 근거: 탈퇴해도 스토어 결제는 계속됨. 안내가 없으면 유저가 돈만 내게 됨

### L5. 가격 인상

- 결정: 출시 뒤 가격 인상은 원칙적으로 하지 않음
- 해야 하는 경우
  - 인상 전 30일 이내에 유저의 별도 동의 필요. 변동 전후 가격, 취소·해지 조건과 방법을 함께 고지
  - 약관에 미리 적어 둔 것, "거부 안 하면 동의"는 인정되지 않음
  - 애플은 한국을 연·비연 구독 모두 "동의 필요"로 분류. 동의하지 않은 구독자는 갱신되지 않음
  - 기존 구독자는 옛 가격 유지, 신규만 새 가격으로 하는 방법이 가장 안전
- 근거: 숨은 갱신 규제. 가격은 한번 정하면 올리기 어렵다는 점이 법으로도 확인됨
- 일시 할인이 끝나 원래 가격으로 돌아가는 것은 증액이 아니라는 가이드라인 해석이 있음. 다만 체험·할인의 유료 전환은 별도 동의 대상 (L6)

### L6. 무료 체험·할인

- 결정: 출시 때 없음 (ADR-0002 D14와 같음)
- 추가된 근거
  - 한국에서는 무료→유료 전환, 할인→정가 전환에 별도 동의가 필요 (2025-02-14)
  - 애플이 동의를 대신 수집하지만, 동의하지 않으면 전환되지 않아 전환율이 떨어질 수 있음
  - 체험·할인이 없는 앱은 이 절차의 대상이 아님 (애플 공지)

### L7. 거래 고지 8종

| 고지 | 언제 | 법적 필요 |
|---|---|---|
| 결제 완료 | 구매·갱신 직후 | 계약 내용 통지 |
| 갱신 예정 | 갱신일 전 | 한국은 권고 단계. 미국 캘리포니아 등은 의무 |
| 가격 변경 동의 요청 | 인상 전 30일 이내 | 한국 의무 |
| 유료 전환 동의 요청 | 체험·할인 종료 전 | 한국 의무 (도입 시) |
| 결제 실패 | 스토어 알림 수신 시 | 없음. 권한 해제 전 안내 |
| 구독 만료 | 만료 시 | 없음 |
| 환불 처리 | 환불 알림 수신 시 | 없음. 권한 회수 사유 안내 |
| 해지 접수 | 자동 갱신을 끈 것을 알았을 때 | 없음. 이용 가능 기간 안내 |

- 거래 고지에는 혜택 홍보, 다른 상품 추천을 넣지 않음. 섞으면 광고성 정보가 되어 L15 규칙이 적용됨
- 근거: 정보통신망법은 영리 목적 광고성 정보에 적용. 거래 관계 정보는 원칙적으로 광고가 아님 (이 구분은 2차 자료 기준, 확인 필요)

### L8. 고지 채널

- 결정
  - 기준: 앱 안 알림함과 해당 화면. 앱을 열면 반드시 보임
  - 보조: 푸시. 꺼져 있을 수 있어 단독으로는 고지로 보지 않음
  - 보조: 이메일. 로그인한 계정에만 있음
- 근거: 비로그인 구매를 허용해(ADR-0002 D9) 연락처가 없는 계정이 있음
- 동의가 필요한 고지(가격 변경)는 앱 안 화면에서 명시적으로 동의·거절을 받음

### L9. 갱신 전 알림

- 결정: 연 구독은 갱신 전에 알림. 월 구독은 보내지 않음
- 며칠 전인지는 L12 규칙 표의 값. 한국 초기값은 14일 전
- 방식: 기기 예약 알림(로컬 알림)과 앱 안 알림함. 서버 푸시가 없어도 됨
- 방미통위 구독 서비스 안내서(2026-05-27)가 "자동결제 전 사전 안내 강화"를 권고
- "갱신일 14일 전까지 개별 통지가 의무"라는 법률 칼럼이 하나 있음. 다른 자료에서 확인되지 않아 전문가 확인 대상. 초기값을 14일로 둔 이유
- 근거
  - 한국: 자동결제 전 사전 고지는 아직 법 의무가 아님. 국민권익위 권고로 문체부가 콘텐츠이용자보호지침 개정을 추진 중이고, 정부의 구독 서비스 개선방안에도 사전 고지가 들어 있음. 의무가 되기 전에 기능을 갖춤
  - 미국 캘리포니아: 연 단위 갱신은 15~45일 전 고지, 가격 변경은 7~30일 전 고지, 해마다 구독 안내
  - 영국: 갱신 알림과 숙려 기간을 담은 구독 규제가 2027년 봄 시행 예정
  - 애플과 구글도 연 구독에 갱신 안내를 보내지만 문구와 시점을 우리가 정할 수 없음

### L10. 동의 기록

- 결정: 동의 표를 둠

| 열 | 내용 |
|---|---|
| 사용자 | 누가 |
| 동의 종류 | 가격 변경, 유료 전환, 광고 수신, 야간 광고 수신, 약관 |
| 문구 버전 | 어떤 문구를 보고 |
| 결과 | 동의 / 거절 |
| 시각, 화면 | 언제, 어디서 |

- 근거
  - 분쟁이 나면 "동의받았다"를 우리가 증명해야 함
  - 캘리포니아는 동의 증빙을 3년 이상 보관하도록 요구
  - 줄을 고치지 않고 쌓음. 철회도 새 줄로 기록

### L11. 고지 발송 기록

- 결정: 보낸 고지마다 사용자, 종류, 채널, 문구 버전, 시각, 결과를 저장
- 근거: "알렸다"의 증빙. 고지 누락을 찾는 데도 씀

### L12. 나라별 규칙 표

- 결정: 고지 규칙을 코드가 아니라 표에 둠

| 열 | 예 |
|---|---|
| 나라 | `KR`, `US-CA`, `GB`, `*`(기본) |
| 고지 종류 | 갱신 예정 |
| 대상 | 연 구독 |
| 시점 | 갱신 7일 전 |
| 필수 여부 | 권고 / 의무 |
| 근거 | 조항이나 출처 |

- 근거: 법이 바뀌거나 나라가 늘어도 줄만 고치면 됨. 한국도 2년 사이 세 번 바뀜
- 나라는 거래의 판매 국가(ADR-0002 D20)로 판단

### L13. 기록 보존

- 결정
  - 계약·청약철회 기록, 대금결제·공급 기록: 5년
  - 소비자 불만·분쟁 처리 기록: 3년
  - 표시·광고 기록: 6개월
  - 탈퇴한 계정의 결제 기록은 지우지 않고 분리해 보관. 보존 기간이 끝나면 삭제
- 근거: 전자상거래법 제6조와 시행령. 기간은 2차 자료 기준이라 시행령 원문 확인 필요
- 개인정보 처리방침에 "법령에 따라 결제 기록을 보관함"을 적음

### L14. 약관과 표시

- 약관에 넣을 것
  - 결제·해지·환불 정책
  - 결제·해지·환불 불만 처리 방법 (문의 창구, 처리 기한)
  - 구독 해지와 환불이 스토어에서 처리된다는 사실
  - 청약철회 기준
- 앱에 표시할 것: 상호, 대표자, 주소, 전화번호, 전자우편주소, 사업자등록번호, 통신판매업 신고번호. 설정에서 한 번에 닿는 화면
- 전화번호와 전자우편주소를 함께 표시해야 함 (전자상거래법 제10조, 제13조). 지금 앱은 문의가 메일뿐
- 근거: 방통위 「앱마켓·모바일콘텐츠 이용자 보호 안내서」의 개발사 권고, 전자상거래법의 사업자 정보 표시 의무
- 약관을 유저에게 불리하게 바꿀 때는 30일 전 공지

### L15. 광고성 알림

- 결정: 거래 고지와 광고 알림을 채널 설정부터 분리
  - 광고 알림은 수신 동의를 받은 사람에게만
  - 밤 9시~아침 8시 발송은 별도 동의
  - 동의 뒤 2년마다 수신 동의 여부 재확인
- 근거: 정보통신망법 제50조. 2년 재확인을 안 하면 3천만 원 이하 과태료라는 안내가 있음
- 지금은 광고 알림 계획이 없음. 구독 권유 푸시를 만들 때 이 규칙을 적용

### L16. 미성년자 결제

- 결정: 따로 연령 확인을 하지 않음. 환불 문의는 스토어 환불 절차로 안내하고, 환불 알림이 오면 권한 회수
- 근거: 환불은 스토어가 결정. 미성년자 결제 취소는 민법 문제이고 개발사의 연령 확인 의무를 정한 1차 자료를 찾지 못함
- 확인 필요

### L17. 구매 내역 화면

- 결정: 설정에 "구매 내역". 결제일, 상품, 금액, 상태(이용 중, 환불됨)를 보여 주고 저장할 수 있게 함
- 근거: 전자상거래법 시행령. 소비자가 거래기록을 열람·확인하고 전자문서로 저장할 수 있게 해야 함

### L18. 알림 채널 구조

- 지금 앱에는 서버 푸시, 이메일, 전화번호가 없음. 유저에게 닿는 수단은 앱 안뿐
- 결정
  - 알림 발송 코드를 채널 인터페이스 뒤에 둠
  - 첫 구현: 앱 안 알림함, 기기 예약 알림
  - 서버 푸시와 이메일은 필요해질 때 구현만 추가
  - 카카오 알림톡은 하지 않음
- 서버 푸시·이메일이 필요해지는 조건: 가격 인상, 무료 체험 도입, 갱신 전 개별 통지 의무 확인, 광고 알림, 해외 판매
- 알림톡을 안 하는 이유: 전화번호 수집, 사업자·채널·딜러사 계약, 템플릿 심사, 건당 비용. 2026-11-01 심사 기준으로 갱신 유도 문구는 발송 불가
- 자세한 판단: [법규 때문에 만들어야 하는 기능](../reports/2026-11-18-compliance-features.md)

## 5. 해외 판매 때 달라지는 것

| 지역 | 규칙 | 상태 | 우리 대응 |
|---|---|---|---|
| EU | "계약 철회" 버튼 의무 (지침 2023/2673) | 2026-06-19 적용 | 14일 철회 경로. 스토어 결제 앱에 어떻게 적용되는지 미확정 |

- 공통점: 표시, 명시적 동의, 쉬운 해지, 갱신 알림. L1, L3, L9, L10이 그대로 쓰임
- 나라마다 다른 것은 시점과 문구. L12 표와 문구 템플릿의 언어판으로 대응
- 지금 하지 않는 것: 나라별 구현. 표와 기록 구조만 열어 둠

## 6. 감수하는 것

- 표 3개(동의, 고지 발송, 나라별 규칙)가 늘어남
- 가격 인상을 사실상 못 함
- 무료 체험으로 전환율을 올리는 방법을 당분간 못 씀
- 갱신 전 알림이 해지를 늘릴 수 있음. 법 방향이 의무화 쪽이라 미리 감수

## 7. 전문가 확인이 필요한 것

- 스토어 결제에서 개발사가 전자상거래법상 통신판매업자인지, 동의 의무의 주체인지
- 동의 시점 표현: 정부 자료는 "증액·전환 전 30일 이내", 애플 공지는 "결제·전환일로부터 30일 이내"
- 구글이 한국에서 유료 전환·가격 인상 동의를 대신 수집하는지
- 디지털 상품의 청약철회 제한을 적용하려면 어떤 조치(표시, 체험 제공)가 필요한지
- 거래 고지가 광고성 정보가 아니라는 구분의 정확한 기준
- 기록 보존 기간의 현행 시행령 조문
- 간이과세자의 통신판매업 신고 면제 여부
- 미성년자 결제에 대한 개발사 의무. 만 14세 미만의 가입·결제
- "갱신일 14일 전 개별 통지" 조항이 실제로 있는지
- 사업자 전화번호 표시 방법
- 2026-11 지침 개정안의 확정 내용과 시행일 (행정예고 중)
