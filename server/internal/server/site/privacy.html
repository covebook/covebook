로그인

서버 동기화를 제공하는 버전은 카카오, Apple, Google 중 하나로 로그인해 사용합니다. 로그인하면 해당 서비스가 제공하는 다음 정보를 받습니다.

· 회원 고유 식별자: 계정 인증과 연결에 사용합니다.
· 닉네임 또는 이름: 앱 화면 표시에 사용합니다. 카카오는 사용자가 동의한 경우에만 받습니다.
· 이메일 주소: 해당 서비스가 확인한 주소만 받으며, '계정 및 동기화' 화면에서 어느 계정으로 로그인했는지 보여 주는 데 사용합니다. 카카오는 사용자가 동의한 경우에만 받습니다. Apple에서 '이메일 가리기'를 고르면 Apple이 만든 전달용 주소를 받습니다.

생년월일, 전화번호, 친구 목록, 메시지 권한과 프로필 사진은 요청하거나 저장하지 않습니다. 이메일은 광고나 다른 목적에 쓰지 않습니다. 카카오·Google의 로그인 토큰은 로그인을 확인하는 동안에만 사용하고 저장하지 않습니다. Apple 로그인은 회원탈퇴 때 Apple 계정 연결을 끊기 위해 Apple이 발급한 갱신 토큰을 암호화해 보관하고, 회원탈퇴하면 Apple에 폐기를 요청합니다. 이메일이나 닉네임이 같다는 이유로 다른 계정을 자동으로 연결하지 않습니다. Google 사용자 데이터는 계정 제공에만 사용하며 광고·판매에 이용하지 않습니다.

로그아웃하면 이 기기에 저장된 기록을 지우며, 서버의 계정과 기록은 남아 다시 로그인하면 받아 옵니다. 각 서비스의 계정 인증과 동의 처리에는 해당 서비스의 개인정보 처리방침이 적용됩니다.

도서 검색과 외부 연결

도서 검색을 실행하면 검색어를 Covebook 서버로 보내고, 서버가 YES24 도서 정보에서 결과를 찾습니다. 서버에 닿지 않거나 결과가 없으면 검색어를 Google Books로 바로 보내고, 그래도 결과가 없으면 Open Library로 보냅니다. '인기 많은 책' 목록도 Covebook 서버에서 받습니다. Google Books·Open Library 결과에서 도서를 고르면 해당 서비스에 그 도서의 상세 정보를 요청합니다. 표지를 표시하려고 YES24·Open Library가 제공한 이미지 주소에 접속하며, 받은 표지는 기기의 임시 저장공간에 최대 90일 보관하고 백업 파일에는 넣지 않습니다. 이 과정에서 검색어, 도서·표지 식별자와 IP 주소 등 요청에 수반되는 통신 정보가 해당 서비스에 전달됩니다. 외부 서비스의 로그 보관·이용은 각 제공자의 개인정보처리방침에 따르며, 개발자는 제공자 로그를 직접 관리하거나 삭제할 수 없습니다. 직접 입력 기능을 이용하면 도서 검색 없이 책을 추가할 수 있습니다.

사진·카메라

사진 선택과 카메라는 사용자가 표지나 갈피 페이지 사진을 추가하거나 바코드로 책을 찾을 때 사용합니다. 사진은 앱 내 저장공간에 복사됩니다. 갈피 사진의 글자 인식과 바코드 읽기는 기기 안(Android ML Kit, iOS Vision)에서 처리하며, 이를 위해 사진을 외부로 전송하지 않습니다. AI 재장정과 사진을 통한 도서 식별 기능은 제공하지 않습니다. 서버 동기화를 제공하는 버전에서는 동기화를 위해 사진이 Covebook 서버에 저장됩니다. 마이크 녹음 기능은 사용하지 않습니다.

공유·백업

사용자가 공유 카드나 갈피 이미지를 공유하면 운영체제 공유 창에서 직접 고른 앱으로 전달됩니다. 공유 이미지에는 개인 메모를 기본으로 포함하지 않습니다.

백업 파일은 사용자가 만들 때만 생성됩니다. Android에서는 기기의 다운로드/책장한켠 폴더에 바로 저장하거나, 공유 창에서 고른 앱(드라이브·메신저 등)으로 보낼 수 있습니다. iOS에서는 공유 창에서 고른 곳으로 보냅니다. 백업 파일에는 위의 기록과 사용자가 찍거나 고른 사진이 들어 있으며, 검색으로 받은 책 표지는 들어 있지 않습니다. 백업 파일을 보관·전달한 곳의 관리는 사용자에게 있으므로 다른 사람과 공유할 때 주의해 주세요.

Android의 기기 백업·기기 이전은 운영체제 설정에 따라 앱 데이터를 포함할 수 있습니다. 이는 앱 자체의 동기화 기능과 구분됩니다.

공개 범위

별점, 한 줄 감상, 긴 감상, 갈피와 독서 기록은 공개되지 않습니다. 커뮤니티를 제공하는 버전에서는 사용자가 커뮤니티에 직접 올린 글과 그때 고른 항목(책 제목·인용 문장·독서 시간 등)만 공개되며, 같은 책의 공개 평가를 보여 주기 위해 그 책의 ISBN을 Covebook 서버에 요청합니다.

광고·분석

현재 앱에는 광고, 광고 식별자 기반 추적, 별도 분석·오류 수집 SDK를 통한 개발자 서버 전송 기능이 없습니다. Google Play·App Store 및 운영체제가 자체적으로 제공하는 진단·백업 기능에는 해당 서비스의 설정과 정책이 적용됩니다.

기기에 저장한 기록은 사용자가 앱에서 삭제하거나 기기 설정에서 앱 데이터를 삭제할 때까지 유지됩니다. 앱 내에서 책을 삭제하면 관련 회차·갈피·장정이 삭제되지만 독서 시간 기록은 책 연결이 없는 기록으로 남을 수 있으며, 내 기록에서 별도로 삭제할 수 있습니다. 앱 제거 또는 앱 데이터 삭제는 앱 저장공간의 데이터를 제거하지만, 직접 내보낸 파일·공유 사본과 운영체제 백업은 별도로 삭제해야 합니다. 외부 검색 서비스의 보관 기간과 삭제 요청은 위 제공자 정책을 확인해 주세요.

회원탈퇴(서버 계정·데이터 삭제)

서버 동기화를 제공하는 버전에서는 '내 정보 › 계정 및 동기화 › 회원탈퇴'에서 서버 계정 삭제를 요청할 수 있습니다. 접수 즉시 해당 계정의 서버 접근을 차단하고 계정, 연결된 로그인과 이메일, 독서 기록, 사진을 백그라운드에서 삭제합니다. 일시적 실패는 재시도하며, 앱에서 접수 성공을 확인하지 못했을 때는 삭제가 끝났다고 간주하지 말고 다시 요청하거나 문의해 주세요. 서버 계정을 삭제해도 이 기기의 기록·사진과 직접 내보낸 사본은 남으므로 각각 삭제해야 합니다.

서버는 복구 후 삭제 계정이 다시 나타나는 것을 막기 위해 계정 번호·생성 시각·삭제 시각만 있는 최소 삭제 기록을 운영 DB와 별도 저장소에 두고 DB 삭제 후 최대 30일간 보관합니다. DB 복구 시 이 기록을 먼저 재적용합니다. 호스팅·외부 서비스의 별도 백업·로그 보관 설정은 별도 확인 대상입니다.

카카오 계정의 연결된 서비스에서 이 앱의 연결을 해제하는 경우에도 본인 확인된 카카오 알림을 받아 해당 Covebook 서버 계정 전체를 삭제합니다. 같은 계정에 연결된 다른 로그인과 독서 기록도 함께 삭제합니다. 위조 알림이나 다른 앱의 알림은 처리하지 않습니다. 연결 해제 재시도에 필요한 카카오 식별자는 최대 7일 이내 정리합니다.
