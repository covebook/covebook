# 결제 법 키트

결제 키트를 붙인 앱이 법규 대응을 빠뜨리지 않게 하는 체크리스트다.

- 기준: 한국, 2026년 11월. 법률 검토 전이다(이슈 #18)
- 근거와 판단 과정: `docs/adr/0003-iap-compliance.md`(L1~L23). 여기서는 L 번호로만 가리킨다
- 책장 한켠의 실제 문구: `docs/legal/notice-templates.md`(T1~T15), 약관 `docs/legal/terms-draft-2026-11-18.md`, 처리방침 `docs/legal/privacy-draft-2026-11-16.md`
- 다른 앱은 위 세 문서를 복사한 뒤 4장의 자리를 바꾸고, 5장의 판단을 그 앱에 맞게 다시 한다

## 2. 서버 키트가 코드로 지키는 것

붙이기만 하면 따로 할 일이 없는 것들이다. 끄거나 바꾸면 해당 L을 다시 본다.

- 지급 근거는 스토어 답이다. 앱이 보낸 값으로 지급하지 않는다
- 환불·취소 알림이 오면 권한을 회수하고 T9 고지를 쓴다(L16)
- 결제 실패 유예, 해지 예약, 만료, 환불이 바뀌는 순간 고지를 한 번 쓴다(L7, L11)
- 연 구독은 갱신 전 고지를 쓴다. 며칠 전인지는 `IAP_RENEWAL_NOTICE_DAYS`(L9). 요금제 주기를 `iap_plans`에 넣어야 돈다
- 상한을 넘게 산 거래는 지급하지 않고, 구글은 자동 환불, 애플은 환불 요청 안내를 쓴다(T15)
- 대상을 끝내 모르는 거래, 결제한 계정이 탈퇴한 거래는 환불한다
- 계정을 지워도 거래·구독·고지 줄은 주인만 비우고 남긴다(L13)
- 샌드박스 거래는 따로 남겨 매출에서 뺀다

## 3. 앱이 할 것(출시 전 점검표)

### 화면

- [ ] 결제 버튼 바로 위에 T1(구독) 또는 T2(한 번 사는 상품). 작은 글씨로 숨기지 않는다
- [ ] 요금제·상품을 미리 고르지 않는다. 어느 것도 "추천"처럼 강조하지 않는다(L2)
- [ ] 거절한 사람에게 같은 결제 권유를 다시 띄우지 않는다(L2)
- [ ] 설정 첫 화면에 "구독 관리". 스토어 구독 관리로 바로 간다. 설문·재확인을 끼우지 않는다(L3, T11)
- [ ] 탈퇴 화면에 "탈퇴해도 구독은 해지되지 않는다" 안내. 탈퇴를 막지 않는다(L4, T12)
- [ ] 구독 혜택마다 결제 전 미리보기(시험 사용). 없으면 청약철회 제한 표시가 효력이 없다(L19, 5장)
- [ ] 결제 완료 화면 또는 고지에 금액, 다음 결제일, 해지하는 곳(T3, L20)
- [ ] 알림함, 구매 내역, 사업자 정보 화면
- [ ] 결제 화면은 빌드 플래그로 끈 채 머지하고, 출시할 때 켠다

### 문서

- [ ] 약관에 유료 조 5개(4장 표의 자리를 바꿔서)
- [ ] 처리방침에 결제 정보 항목, 처리 근거, 보존 기간(5장)
- [ ] 통신판매업 신고, 사업자 정보를 배포 환경의 `IAP_SELLER_JSON`에
- [ ] 스토어 심사 메모(T14)

### 운영

- [ ] 스토어 콘솔의 상품 ID와 `iap_products` 줄이 같다
- [ ] 연 구독이 있으면 `iap_plans`에 주기
- [ ] 스토어 알림 주소 등록(애플 v2, 구글 Pub/Sub 푸시와 OIDC 인증)
- [ ] 결제·환불 문의를 받는 곳과 처리 기록(L21)

## 5. 앱마다 다시 판단할 것

책장 한켠에서 내린 판단이 다른 앱에서는 달라질 수 있는 것들이다. 출시 전에 하나씩 다시 본다.

- **청약철회 제한(전자상거래법 제17조 제2항 제5호, 제6항)**
  - 디지털콘텐츠는 "제한 사실 표시"와 "시험 사용 상품 제공"이 둘 다 있어야 제한된다
  - 혜택이 바뀌면 미리보기도 같이 만든다. 미리보기가 없는 혜택은 제한을 주장하기 어렵다
- **통신판매업자 지위**
  - 스토어 결제에서 개발사가 통신판매업자인지는 자료가 엇갈린다. 책장 한켠은 통신판매업자로 보고 준비했다
- **미성년자**
  - 결제 취소 고지(제13조 제3항)는 나이를 확인하지 않으면 모든 구매자에게 보인다(T1 v3)
  - 14세 미만 가입을 받으면 처리방침에 법정대리인 권리(개인정보보호법 제38조 제2항)를 적는다
  - 14세 미만 법정대리인 동의(제22조의2)는 동의를 근거로 처리할 때만 걸린다. 결제 기록은 계약 이행과 법정 보존이 근거라 동의 대상이 아니다. 앱에 동의를 근거로 한 처리(광고·분석 SDK, 선택 항목)가 있으면 다시 본다
- **개인정보 처리 근거**
  - 결제 기록: 계약 이행(제15조 제1항 제4호)과 법령상 보존(전자상거래법 시행령 제6조, 5년)
  - 사업자 정보(`seller`)는 사업자의 정보라 처리방침 대상이 아니다
- **나라**
  - 해외에 팔면 나라별 고지 규칙(L12)과 스토어 가격 인상 동의 분류가 달라진다. 키트는 지금 한국 기준이다
- **광고성 알림**
  - 거래 고지에 혜택 홍보나 다른 상품 추천을 넣으면 광고성 정보가 된다(L15)
- **콘텐츠이용자 보호지침과 다른 점**
  - 지침의 알림·동의 조항을 따르지 않는 부분은 약관에 적는다(L23)
- **외부 제공 정보**
  - 앱이 외부 데이터(책장 한켠: 도서 표지)를 쓰면 그것이 유료 혜택이 아님을 약관에 적는다(T13-1). 고의·과실 책임까지 빼는 문구는 무효다
